1. كل عنصر ظاهر في صفحة المرجع له سجل مطلب قابل للتتبع.

5. البيانات المالية والمخزنية تتحدث باتساق وبمعاملة ذرية.

7. اختبارات رجعية ناجحة، ولا يوجد ادعاء بالاكتمال دون دليل.

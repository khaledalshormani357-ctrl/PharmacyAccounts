### قاعدة قرار النقص
قبل وصف أي ميزة بأنها «غير موجودة»، ابحث في شاشة المسار، المكونات المشتركة، خدمات `services/`، طبقة التخزين/قاعدة البيانات، وتدفق التنقل. بعد ذلك صنّفها: مكتملة، جزئية، مفقودة، أو غير محسومة، مع روابط الملفات والاختبارات ذات الصلة.

4. إضافة OCR فاتورة الشراء كمسودة قابلة للمراجعة فقط، مع عدم الترحيل دون تأكيد صريح.
5. إكمال خريطة المرتجعات والتقارير والطباعة بعد تتبع الخدمات واختبار كل مسار.
